# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be decent to people. Assume good faith, critique the work rather than
the person, and take the hint when someone asks you to drop something.

Report problems by opening an issue, or privately to the repository owner via
their GitHub profile. Reports will be handled discreetly.
